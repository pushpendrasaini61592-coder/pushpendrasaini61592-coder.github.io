Free publishing with GitHub Pages:
1. Sign in to https://github.com
2. Create a public repository named YOUR-USERNAME.github.io (replace YOUR-USERNAME with your actual GitHub username).
3. Upload index.html and profile-hero.png to the repository root.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait for GitHub Pages deployment and open the URL shown in Settings > Pages.
Never share your password or email verification code in chat.
